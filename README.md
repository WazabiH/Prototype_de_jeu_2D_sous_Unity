# Jeu vidéo 2D sous Unity

## Présentation

Ce projet a été réalisé dans le cadre d'un exercice de découverte du moteur Unity.

L'objectif était de mettre en pratique les bases du développement de jeux vidéo 2D en travaillant sur l'interface utilisateur, la gestion des états du jeu et la création d'un environnement à l'aide du système de tuiles (Tilemap).

## Objectifs du projet

* Mettre en place un menu de pause.
* Utiliser les Scriptable Objects pour gérer certains éléments du jeu.
* Ajouter des boutons permettant de relancer la partie.
* Bloquer les déplacements du joueur lorsque le jeu est en pause.
* Construire un décor 2D à l'aide de tuiles.
* Séparer le décor en plusieurs plans (sol et arrière-plan).

## Technologies utilisées

* Unity
* C#
* Tilemap
* Scriptable Objects

## Fonctionnalités réalisées

* Menu pause accessible en jeu.
* Bouton de reprise de partie.
* Bouton de redémarrage.
* Désactivation des déplacements pendant la pause.
* Création d'un environnement 2D avec Tilemap.
* Mise en place d'un premier plan et d'un arrière-plan.

## Compétences développées

Ce projet m'a permis de découvrir :

* L'environnement Unity.
* Le développement de scripts en C#.
* La gestion d'interfaces utilisateur.
* L'utilisation des Scriptable Objects.
* La création de niveaux avec Tilemap.
* Les bases de la programmation événementielle dans un jeu vidéo.

## Lancer le projet

1. Cloner le dépôt.
2. Ouvrir le projet avec Unity.
3. Charger la scène principale.
4. Exécuter le projet depuis l'éditeur Unity.
